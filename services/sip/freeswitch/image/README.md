# FreeSWITCH 1.11.3 candidate

This source build is an upgrade candidate. Production Compose retains its
previous image digest until the new image is published and release gates pass.
It does not use an assumed third-party `1.11.3` tag or the upstream legacy
Debian Jessie release Dockerfile.

FreeSWITCH, Sofia-SIP and SpanDSP source revisions are pinned in the Dockerfile.
The runtime stage contains shared dependencies, binaries, modules and vanilla
configuration, with no compiler or source tree. Build the deployment platform:

```sh
docker build --platform linux/amd64 -t vocivo-freeswitch:1.11.3-candidate services/sip/freeswitch/image
VOCIVO_TEST_FS_IMAGE=vocivo-freeswitch:1.11.3-candidate python3 services/sip/tests/validate_forward_auth.py
VOCIVO_TEST_FS_IMAGE=vocivo-freeswitch:1.11.3-candidate python3 services/sip/tests/validate_gateway_load.py
VOCIVO_TEST_FS_IMAGE=vocivo-freeswitch:1.11.3-candidate python3 services/sip/tests/validate_byoc.py
VOCIVO_TEST_FS_IMAGE=vocivo-freeswitch:1.11.3-candidate python3 services/sip/tests/validate_features.py
```

Run generated BYOC dialplans, Digest/RTP, XML-curl, recording, hold music and the
receptionist event-socket flow against this same image before publishing it.
App hold music is mounted from `services/sip/freeswitch/sounds`; the source build
does not download a substitute music collection. All required media assets must
be present on the deployment host.

Build output and a successful version command do not prove carrier audio or
device recovery. Record the final registry digest and dependency provenance,
then change the Compose pin as a separate reviewed promotion. Preserve the old
image, drain calls, back up configuration and migrate existing spool/recordings
before restarting services. Never roll back by discarding persistent delivery
volumes. Actual Go Telecom, mobile/WebRTC, DTMF, AI transfer, voicemail and long
call acceptance remain deployment gates.

The September 10 local amd64 candidate reported `1.11.3-release~64bit` and
passed gateway loading, the Kamailio credential boundary, tenant-specific
G.711/Opus RTP, capacity release, final hangup duration, required-module loading,
local audio recording and event-socket disconnect fallback. This is local
compatibility evidence; the image has not been published or deployed. Debian's
base image is digest-pinned; package versions are resolved during build, so
retain the tested image rather than assuming a later rebuild is byte-identical.
